The Mathematics

The system calculates four primary measures of central tendency for a given set of positive numbers:

  • Arithmetic Mean (AM): The standard average (sum divided by count). Out of the Pythagorean means, this will always return the highest value.
  • Geometric Mean (GM): The n-th root of the product of all numbers. Useful for calculating compound growth.
  • Harmonic Mean (HM): The reciprocal of the average of the reciprocals. Useful for averaging rates (like speed). This always returns the lowest value.
  • Median: The exact middle value of a sorted list.

Why does it converge?

This process is guaranteed to converge to a single number because of the strict inequality of the Pythagorean Means, which dictates that for any non-identical set of positive numbers: HM < GM < AM.

On every iteration:

  1. The maximum boundary (the Arithmetic Mean) gets pulled down.
  2. The minimum boundary (the Harmonic Mean) gets pulled up.
  3. The Median behaves as a chaotic anchor that prevents the AM, GM, and HM from cancelling out instantly through algebraic symmetry (which would happen if you only used those three).

Because the new values are always strictly bounded inside the previous generation's minimum and maximum, the dataset acts like a mathematical vise, squeezing the numbers closer and closer until they all equal exactly the same thing.
